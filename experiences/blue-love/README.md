# Blue Love - Interactive Particle Video Generator

A high-performance HTML5 Canvas & Web Audio interactive animation application built with React, TypeScript, and Vite.

## Features

- **Particle & Morphing Physics Engine:** Real-time particle morphing into dynamic typography and custom 3D parametric heart shapes.
- **Custom Web Audio Synthesizer:** Procedural ambient melody, heartbeat sound synthesis, and transition chimes built natively with Web Audio API.
- **Canvas Video Recording:** High-definition video recording directly from the browser using MediaRecorder API.
- **Visual FX System:** Aurora Borealis waves, Cosmic Vortex swirl transitions, Starburst outer halo ring, and meteor trails.

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation & Running

1. Install project dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Tech Stack

- **Frontend:** React 19, TypeScript
- **Build Tool:** Vite 6
- **Styling:** Tailwind CSS v4, Lucide Icons
- **Graphics & Sound:** HTML5 2D Canvas Context, Web Audio API Context
